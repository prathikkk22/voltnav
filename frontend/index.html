Dataset Architecture & Pipeline

How Kaggle dataset data transforms into an intelligent full-stack EV application.

01

Kaggle Raw Dataset

Indian EV charging station dataset imported into Google Colab containing raw station names, coordinates, and network categories.

1,547 Raw Records
02

Colab Cleaning Pipeline

Standardizes coordinates, fixes inverted GPS points, cleans city/state names, parses operator brands, and generates slot topologies.

Pandas + Zero Duplicates

Backend REST API

Interactive Modern Frontend

Dataset Column Inspection & Application Usage

Dataset Column Raw Kaggle Type Data Cleaning & Transformation Application Usage in VoltNav
name String Stripped quotes, extracted operator brands (Tata, Statiq, Ather, IOCL). Primary station title, operator badge, brand search filter.
state String Standardized typos (e.g. TamiNadu → Tamil Nadu, Harayana → Haryana). State dropdown filter, regional grouping, location hierarchy.
city String Title-cased (e.g. bengaluru → Bengaluru, gurgaon → Gurugram). City search filter, quick city chips, location card badge.
address String Filled missing addresses with formatted city/state fallback. Address display on station cards, modal details, Google Maps directions.
lattitude Float Fixed dataset typo name, corrected inverted lat/lon coordinates. Leaflet map pins, GPS "Near Me" Haversine distance ranking.
longitude Float Validated geographic boundary inside India (68°E to 98°E). Interactive map placement, navigation routing.
type Integer (6, 7, 12) Mapped network codes into charger specs (DC Fast, Dual AC/DC, AC Type 2). Power rating (kW), voltage, speed tier, connector types (CCS-2, CHAdeMO).
slots (Enriched) Object Array Derived 2-4 ports based on station class + live simulation states. 🟢 Available / 🟠 Occupied slot visualizer, interactive reservation modal.
